## Core Technical Case: UAV Telemetry Optimization

During my consultancy at **SITELBRA**, I took ownership of the real-time telemetry and video streaming pipelines for DJI Drone fleets.

| Metric | Before | After | Improvement |
| :--- | :---: | :---: | :---: |
| **End-to-End Latency** | 2000ms | 35ms | **~57x Reduction (98.2%)** |

* **Stack used:** MQTT (HiveMQ), WebSockets, AWS Lambda (Serverless/Event-Driven), Java, Python, and TypeScript.
* **Key takeaway:** High fault tolerance, migration of legacy code with critical compliance (LGPD/GDPR), and sharp edge-computing integration.
